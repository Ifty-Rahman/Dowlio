# Dowlio

A fast, reliable, private, native download manager for macOS. It should feel native, stay lightweight, and let the user download everything from media to files reliably and fast even from websites that don't have a download button.

The app has two main workflows:
1. Capture downloads : It should capture every downlaod from the browser and complete it in the app
2. Send to app : User can send a page to the app and the app will analyse what downloads there on the page the and give the user options for download.
